Privacy Policy

Last updated: 21 November 2026

This policy covers Alkaautsar Poster ("the tool"), the software the Alkaautsar team uses to publish its own videos to Alkaautsar's own accounts, and this website.

What we collect

Nothing about viewers or other users. The tool only connects to Alkaautsar's own YouTube, Instagram and TikTok accounts. When the account owner signs in, the platform gives the tool an access token and basic profile information (account ID, display name, avatar) so it can confirm it is posting to the right account.

How it is used and stored

The access tokens are used only to upload Alkaautsar's approved videos and their captions, and to read the creator settings the platform requires before posting. They are kept in a private configuration file on our own computers, are never shared or sold, and are not used for advertising, analytics or profiling. The links to published posts are kept in our internal content planning sheet.

This website

This website uses no cookies, trackers or analytics. It is hosted on GitHub Pages; GitHub may keep standard server logs as described in its own privacy statement.

Removing access

The account owner can revoke the tool's access at any time in each platform's settings (Google account permissions, Instagram apps and websites, TikTok manage app permissions). We then delete the stored token.

Children

The tool is not directed at children and collects no data from anyone.

Changes and contact

We may update this policy; the date above shows the latest version. Questions: send a direct message to @alkaautsar_ on Instagram.
